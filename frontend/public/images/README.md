# Image slots

Drop real photos here with these exact names and they appear automatically
(the site shows an SVG/gradient placeholder until each file exists).

| File | Used on | Suggested size |
|---|---|---|
| `hero.jpg` | Homepage hero background (technician / clean duct, dark-ish, landscape) | 2000×1200 |
| `before.jpg` | Before/after slider — dirty duct | 1600×900 |
| `after.jpg` | Before/after slider — clean duct | 1600×900 (same framing as before.jpg) |
| `about.jpg` | About page story section | 1200×1400 (portrait) |
| `services/<slug>.jpg` | Service detail page header, e.g. `services/air-duct-cleaning.jpg` | 1600×900 |
| `blog/<slug>.jpg` | Blog card + post header, e.g. `blog/dryer-vent-fire-safety.jpg` | 1200×675 |
| `team.jpg` | Optional — About page team photo | 1600×900 |

Tips: export as JPG (quality ~80) or WebP; keep each under ~300 KB; landscape shots with the
subject on the left or right work best because text overlays the other side.
